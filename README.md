# Kampung Wira consolidated prototypes

This folder is a consolidated copy of the original prototype collection.

- Pages: `pages/`
- Shared CSS: `shared/css/`
- Shared JavaScript: `shared/js/`
- Shared JSON: `shared/json/`
- Shared downloaded images and screenshots: `shared/images/`
- Shared downloaded fonts: `shared/fonts/`
- Preserved design system: `DESIGN.md`

The original folders remain in place, and each source `code.html` has also been renamed to `<parent-folder>.html`. Consolidated page files use the same parent-folder names so every page has a unique filename.
